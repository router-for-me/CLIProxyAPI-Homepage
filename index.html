BUILT FOR THE COMMAND LINE

Six reasons developers live in CLIProxyAPI.

No bloated GUI wrappers required—just a single compiled Go binary designed for shells, SSH sessions, containers, and local workstations.

Zero-Key CLI OAuth

Authenticate Codex, Claude Code, Antigravity, Kimi, xAI, Meta, and Devin directly from your terminal, including headless --no-browser and device-code flows.

cli-proxy-api --claude-login --no-browser

Universal Protocol Bridge

Expose OpenAI (Chat & Responses), Anthropic Messages, and Gemini (including Interactions) endpoints with streaming SSE, WebSockets, tools, and vision.

/v1/chat/completions · /v1/responses · /v1/messages

Multi-Account Round-Robin

Pool multiple CLI subscriptions and API keys per provider. Requests rotate across healthy credentials automatically to smooth out rate limits.

auths/codex-01.json + auths/codex-02.json

Bubbletea Terminal UI

Launch an interactive full-screen terminal dashboard with --tui --standalone to inspect accounts, manage API keys, trigger OAuth, and tail live logs.

cli-proxy-api --tui --standalone

LAN Gateway Discovery

Run cli-proxy-api discover to scan _ai-gateway._tcp via DNS-SD on your local network, with clean --json output ready for shell pipelines.

cli-proxy-api discover --timeout 3 --json

Embeddable Go SDK & Stores

Embed sdk/cliproxy directly into Go services, hot-reload YAML config, and persist credentials on disk, PostgreSQL, Git, or Object Storage.

import "github.com/router-for-me/CLIProxyAPI/v8/sdk/cliproxy"

THREE-STEP TERMINAL SETUP

Up and routing in sixty seconds.

Build from Go 1.26+ source or download a prebuilt binary, log in from your shell, and start serving requests locally.

STEP 01 · BUILD & CONFIG [01/03]

Compile the CLI binary

Build the single Go binary and initialize config.yaml from the included template.

go build -o cli-proxy-api ./cmd/server && cp config.example.yaml config.yaml
STEP 02 · AUTHENTICATE [02/03]

Log in via CLI OAuth

Sign in with one flag—credentials are stored cleanly under auths/ for round-robin routing.

./cli-proxy-api --claude-login
STEP 03 · SERVE OR TUI [03/03]

Launch server or Terminal UI

Run headless in the background or open the built-in Bubbletea TUI console.

./cli-proxy-api --tui --standalone
